# PHANES interim public notice

Single-page **unaudited / experimental / high risk** notice for hosting without ChatGPT Sites.

## Files

- `index.html` — drop this as the site root page

## Host (pick one)

### GitHub Pages
1. Create a new repo (e.g. `phanes-notice`).
2. Upload `index.html` (root of repo, or `/docs`).
3. Settings → Pages → deploy from branch.
4. Open the `*.github.io` URL and confirm the banner is visible.

### Cloudflare Pages
1. Free Cloudflare account → Workers & Pages → Create → Upload assets.
2. Upload folder containing `index.html`.
3. Use the `*.pages.dev` URL.

### Netlify Drop
1. https://app.netlify.com/drop  
2. Drag the folder with `index.html`.  
3. Use the generated URL.
